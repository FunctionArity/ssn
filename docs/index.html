Sistema de Gestión Pastoral

Servicio Sacerdotal Nocturno

Sistema de asignación y seguimiento de guardias nocturnas para el servicio sacerdotal, asegurando cobertura continua y organizada.

Funcionalidades

Todo lo necesario para la gestión de guardias

Una plataforma centralizada para coordinar sacerdotes, vocales y guardianes durante los turnos nocturnos de servicio pastoral.

🌙

Guardias Nocturnas

Creación y seguimiento de turnos. Las guardias se generan a partir de plantillas o manualmente, con estado abierto o cerrado.

📅

Planificación de Plantillas

Configuración de guardias recurrentes por día del mes. Los sacerdotes se asignan por semana y día con cálculo automático de fechas.

✝️

Registro de Servicios

Documentación de cada servicio pastoral: datos del paciente, domicilio, patología, sacramentos administrados y centro de salud.

📄

Exportación a PDF

Generación de actas en PDF al cerrar una guardia, con previsualización, confirmación de numeración y descarga final.

👥

Gestión de Usuarios

Registro por invitación con tres roles. Soporte para bloqueo, impersonación de cuentas y avatares en la nube.

📆

Calendario de Sacerdotes

Vista mensual interactiva que muestra las asignaciones de sacerdotes por día, con navegación entre meses.

Roles

Tres perfiles de usuario

El sistema define roles claros para estructurar la responsabilidad dentro de cada guardia.

Guardián

Guardián

Miembro asignado a la guardia. Participa activamente durante el turno nocturno.

Vocal

Vocal

Coordina y supervisa la guardia. Responsable de registrar los servicios realizados.

Sacerdote

Sacerdote

Administra los sacramentos durante la guardia. Asignado según calendario mensual.
