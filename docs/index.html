¿Cómo funciona el sistema?

  • Se crean Guardias para cada turno nocturno, asignando sacerdote, vocal y guardianes.
  • Durante la guardia, el vocal registra los Servicios prestados a los fieles.
  • Al finalizar el turno, la guardia se cierra y se genera un informe PDF con el resumen.
  • El historial queda disponible para consulta y seguimiento posterior.
